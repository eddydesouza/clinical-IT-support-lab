# clinical-IT-support-lab
OpenEMR | Docker | Ubuntu Linux | Healthcare IT

# Project Overview

This project is a hands-on Healthcare IT laboratory designed to develop and demonstrate practical skills in Electronic Health Record (EHR) application support, system deployment, clinical workflow testing, incident management, and technical troubleshooting.

The lab uses OpenEMR, an open-source EHR platform, to simulate clinical operations and investigate common technical issues encountered by healthcare IT support teams.

# Project Objectives

- Deploy and configure an EHR application in a Linux environment.

- Simulate clinical workflows involving fictional patients and healthcare professionals.

- Configure application users, roles, and access permissions.

- Develop and execute clinical workflow test cases.

- Investigate and document simulated application incidents.

- Practice incident management and resolution procedures.

- Develop technical documentation and troubleshooting guides.
